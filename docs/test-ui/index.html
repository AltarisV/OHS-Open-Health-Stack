Configuration

Set your port-forward addresses and credentials here. Values are stored in memory only and auto-filled into all steps below.

⚠ Start the proxy, not a plain file server. With port-forwards running:
python scripts/test-ui-proxy.py → open http://localhost:8888/test-ui/
Why a proxy: this is a browser page, so every call is subject to CORS. Served from a plain http.server, the page is one origin and each port-forward is another, and only EHRbase and Keycloak send CORS headers at all - Eos, openFHIR and the Cohort Explorer backend send none, so Steps 4, 6 and 7 could never read a response. Eos is the worst of them: its POST is a "simple request", so the conversion does run and only the response is withheld, which looks like a failure that changed nothing. test-ui-proxy.py serves this page and forwards /svc/<name> to each service, so everything shares one origin and CORS never applies. The address fields below are those proxy paths; put absolute URLs there only if you have some other single-origin setup. Behind the ingress/gateway this is all moot - one origin already.
